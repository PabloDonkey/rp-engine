# S024 · Memory layer 02 — lorebook

**Status:** ✅ COMPLETE — 2026-09-03.

## Goal

Build the lorebook layer ADR-026 designed and reserved this id for, using a character named
Jane as the pilot content — not a bespoke Jane-only system, per the handoff document that
prompted this work.

## Scope

- [x] `LoreEntry` domain type (`core/scenario/lore_entry.py`) — `id`, `title`, `content`,
      `trigger_keys`, `priority` (`low`/`normal`/`high`, a per-entry tie-break), and inert
      `related_entry_ids`. No `summary` field — `content` is already meant to be short.
- [x] `LorebookStore` port (`core/ports/lorebook_store.py`) and `PostgresLorebookStore`
      (`infrastructure/postgres/repositories/lorebook_store.py`), with the matching query
      as the one documented ADR-013 exception layer 02 already takes.
- [x] `lorebook_entries` table, migration `20260903_0014`, composite PK
      `(scenario_definition_id, id)`, cascades from `scenario_definitions`. Verified
      reversible (`upgrade head` / `downgrade -1` / `upgrade head`) against the real local
      Postgres.
- [x] `LorebookSource` (`core/memory/lorebook_source.py`), wired into `MemoryPipeline` in
      `app/main.py`. `PRIORITY_LOREBOOK = 60`, between the rolling summary (80) and the
      not-yet-built layers 03/04.
- [x] Scenario JSON transfer format extended with an optional `lorebook` array —
      `ScenarioTransferService.import_directory`/`import_scenario_payload`/`export_scenario`
      all carry it now, alongside the scenario itself.
- [x] Admin backend CRUD (`AdminService` + `admin_routes.py`,
      `/admin/scenarios/{id}/lorebook[...]`) and the Vue admin UI
      (`LorebookSection.vue`, mounted on `ScenarioDetailPage.vue`), with a component test
      (5 cases) alongside the existing frontend suite.
- [x] Jane pilot data: `data/catalog/jane-butcher-shop.json`, four entries
      (`jane_accident`, `jane_lost_friendship`, `jane_learning_restraint`,
      `jane_butcher_shop`), triggers rewritten after real-data testing surfaced that the
      handoff document's literal trigger phrasing did not fire in practice.
- [x] `docs/MEMORY.md` layer 02 write-up (matching, and building on the style of layers 00
      and 01) and `docs/SCENARIOS.md`'s `lorebook` field documentation.
- [ ] Postgres contract test — deliberately deferred, see the frozen banner.
- [ ] Live Telegram run — not done this session.
